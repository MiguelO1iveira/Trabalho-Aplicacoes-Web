# 🌐 KNIGHT-TECH

Projeto desenvolvido para a disciplina de **Aplicações Web** do curso de **Engenharia de Software**.

O projeto consiste no desenvolvimento de um **portfólio pessoal**, criado com o objetivo de apresentar informações sobre minha formação, conhecimentos, cursos, projetos e formas de contato, utilizando tecnologias fundamentais para o desenvolvimento de páginas web.

🔗 **Projeto publicado:**
https://miguelo1iveira.github.io/Trabalho-Aplicacoes-Web/

---

## 📖 Sobre o Projeto

O **KNIGHT-TECH** é um site desenvolvido como atividade acadêmica, com a finalidade de aplicar na prática conceitos de desenvolvimento web.

A página foi estruturada para apresentar informações pessoais e acadêmicas de forma organizada, além de reunir alguns dos projetos desenvolvidos durante minha trajetória de estudos na área de tecnologia.

O site possui diferentes seções para facilitar a navegação e apresentar o conteúdo de maneira clara e objetiva.

### 📌 Principais seções

* **Sobre mim:** apresentação pessoal e interesses na área de tecnologia.
* **Formação:** informações sobre minha formação acadêmica e técnica.
* **Cursos e conhecimentos:** apresentação de cursos e conteúdos estudados.
* **Portfólio:** projetos e trabalhos desenvolvidos ao longo da formação.

---

## 🎯 Objetivos

O desenvolvimento deste projeto teve como principais objetivos:

* Aplicar conceitos fundamentais de desenvolvimento web;
* Praticar a construção e organização de páginas HTML;
* Utilizar CSS para estilização e apresentação visual;
* Criar uma estrutura de navegação entre diferentes partes do site;
* Desenvolver uma interface simples, organizada e acessível;
* Publicar uma aplicação web utilizando o **GitHub Pages**.

---

## 📂 Estrutura do Projeto

A estrutura do projeto é organizada de forma a separar os principais arquivos utilizados na aplicação.

```text
Trabalho-Aplicacoes-Web/
│
├── index.html
├── css/
│   └── style.css
├── imagens/
│   └── ...
└── README.md
```

> A estrutura acima representa a organização principal do projeto. Os nomes e diretórios podem variar conforme a versão atual do repositório.

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como parte das atividades do curso de **Engenharia de Software**, tendo como foco a aplicação prática dos conhecimentos relacionados ao desenvolvimento de aplicações web.

Além de cumprir os requisitos propostos na disciplina, o projeto também serviu como oportunidade para organizar e apresentar minha trajetória acadêmica e meus estudos na área de tecnologia.

---

## 📚 Aprendizados

Durante o desenvolvimento do projeto, foi possível praticar conceitos importantes relacionados ao desenvolvimento web, principalmente a estruturação de páginas utilizando HTML e a estilização utilizando CSS.

Também foi possível compreender melhor a organização de um projeto web, a criação de menus de navegação, a apresentação de conteúdos de forma estruturada e o processo de publicação de uma aplicação utilizando o GitHub Pages.
